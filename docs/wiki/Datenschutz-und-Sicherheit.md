# Datenschutz und Sicherheit

Das Plugin lädt keine Analyse-, Font- oder Werbedienste nach. Die lokalen Bedienhilfen speichern ausschließlich Darstellungswünsche im Browser-Speicher. Der GitHub-Check übermittelt keine Shop-, Kunden- oder Zugangsdaten. Konfigurationswerte werden nur in der Shopware-Datenbank des Shops gespeichert.

Die Admin-Seite **Weitere Plugins** ruft vom Shop-Server aus die öffentliche Liste auf theme.michael-gahn.de ab. Dabei sieht der Server die IP-Adresse des Shop-Servers, aber keine Shop-, Kunden- oder Zugangsdaten. Bilder lädt der Browser nur auf dieser Admin-Seite; dort sieht der Server die IP-Adresse der angemeldeten Person. Für Besucher des Shops entsteht keine Verbindung zu theme.michael-gahn.de.
