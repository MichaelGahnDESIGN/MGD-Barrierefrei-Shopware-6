# Bedienhilfe für Besucher

Die Bedienhilfe ist der runde Button unten links oder rechts im Shop.
Besucher können damit die Seite besser lesbar machen.

## So sieht sie aus

- Ein rundes Symbol mit einer Person im Kreis.
- Fährt die Maus darüber, erscheint daneben der Text (z. B. „Barrierefreiheit“).
- Ein Klick öffnet das Fenster mit allen Funktionen.

## Diese Funktionen gibt es

Jede Funktion hat ein Symbol und ein **(?)**. Ein Klick auf das (?) erklärt kurz, was sie tut.

| Funktion | Was passiert |
|---|---|
| Schriftgröße | Alle Texte werden größer oder kleiner (90 bis 150 Prozent). |
| Hoher Kontrast | Heller Text auf schwarzem Grund, Links in Gelb. |
| Graustufen | Alle Farben verschwinden. |
| Mehr Abstand | Mehr Platz zwischen Zeilen, Wörtern und Buchstaben. |
| Lesbare Schrift | Eine klare, einfache Schrift statt verspielter Schriften. |
| Links hervorheben | Alle Links werden unterstrichen und umrahmt. |
| Fokus sichtbar | Ein dicker Rahmen zeigt, wo man mit der Tab-Taste gerade ist. |
| Bewegung stoppen | Animationen und Videos halten an. |
| Großer Mauszeiger | Ein großer, gut sichtbarer Mauszeiger. |
| Lese-Lineal | Ein Balken folgt der Maus und hilft beim Lesen (nur mit Maus). |

Oben im Fenster können Besucher außerdem wählen:

- **DE / EN**: Sprache der Bedienhilfe.
- **Dunkles Design**: Fenster hell oder dunkel.

Alles wird nur im Browser des Besuchers gespeichert. Es geht nichts an deinen Server oder an andere.

## Standard einstellen (für dich als Shop-Betreiber)

1. In Shopware: **Erweiterungen → Meine Erweiterungen → MGD Barrierefrei → Konfigurieren**.
2. **Standard-Sprache** wählen:
   - *Automatisch* nimmt die Sprache deiner Seite.
   - *Deutsch* oder *Englisch* legt sie fest.
3. **Standard-Design** wählen:
   - *Automatisch* folgt dem Gerät des Besuchers (hell oder dunkel).
   - *Hell* oder *Dunkel* legt es fest.
4. Optional: **Beschriftung Deutsch** und **Beschriftung Englisch** ändern.
5. Optional: **Abstand nach oben** erhöhen, wenn der Button einen anderen Button verdeckt (z. B. Chat). Beispiel: 70.
6. Speichern. Danach **Einstellungen → Caches & Indizes → Caches leeren**.

Besucher können Sprache und Design trotzdem jederzeit selbst umstellen. Der Standard gilt nur beim ersten Besuch.

## Gut zu wissen

- Die Bedienhilfe ersetzt keine barrierefreie Website. Sie ist eine Hilfe zusätzlich.
- Texte in eingebetteten fremden Inhalten (z. B. YouTube-Videos, Karten in einem iframe) werden nicht vergrößert.
