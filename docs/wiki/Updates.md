# Updates

## Ab Version 1.6.0

1. Öffne in Shopware **Einstellungen → Erweiterungen → MGD Barrierefrei**.
2. Dort steht „Du hast die aktuelle Version“ oder „Version X ist verfügbar“.
3. Bei einer neuen Version klickst du **Jetzt aktualisieren**.
4. Das Plugin holt die ZIP-Datei aus dem GitHub-Release und prüft Größe und Prüfsumme (SHA-256). Nur wenn alles stimmt, wird sie eingespielt.
5. Danach steht dort „Fertig“. Lade die Seite neu.

Klappt es nicht, zeigt die Seite einen Download-Link und diese Schritte:

1. ZIP-Datei über den Link herunterladen.
2. In Shopware **Erweiterungen → Meine Erweiterungen → Erweiterung hochladen** öffnen und die ZIP-Datei wählen.
3. Beim Plugin auf **Aktualisieren** klicken.

Es gibt kein automatisches Update. Vorher Datenbank und Plugin-Dateien sichern.

## Bis Version 1.5.1

Lade die ZIP-Datei aus dem GitHub-Release selbst in Shopware hoch und führe das Update über die Shopware-Administration aus.
