# Erklärung vor Veröffentlichung prüfen

Der Text ist eine Vorlage. Prüfe die Angaben gegen den tatsächlichen Stand des Shops und die für dein Angebot geltenden Anforderungen. Ergänze bekannte Barrieren konkret und halte eine erreichbare Kontaktmöglichkeit aktuell. Das Plugin ersetzt keine Rechtsberatung und keine fachliche Prüfung.
